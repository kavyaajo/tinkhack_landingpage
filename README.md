  TinkHack Landing Page  

A responsive landing page built for **TinkerHub MEC's flagship hackathon – TinkHack**.  
This project was created as part of the **TinkerHub Tech Team eRecruitment Task**.  

---

 Features  
-  **Event Overview** – Clear details about TinkHack  
-  **Timeline** – Day-by-day schedule  
-  **Registration Form** – Simple and interactive form with validation  
-  **Sponsors Section** – Highlighting supporting partners  
-  **Contact Section** – Easy way to reach out  
- Fully responsive design (mobile + desktop)  

---

##  Tech Stack  
- **HTML5** – Page structure  
- **CSS3** – Styling, responsiveness, animations  
- **JavaScript (ES6)** – Form handling & interactivity
